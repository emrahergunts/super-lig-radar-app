# Süper Lig Radarı · Not gir (Telegram Web App)

Süper Lig Değer Radarı botunun içinde açılan küçük form sayfası. Takım ve kriteri seçip gönderirsin;
sayfa komutu Telegram üzerinden bota iletir, bot 3 saat içinde onaylar, rapor notu "senin notun" diye işaretler.

Bu depo yalnızca statik bir sayfa içerir: veri, token, rapor yoktur. Asıl sistem özel depodadır.

GitHub Pages ile yayınlanır: Settings → Pages → Deploy from a branch → main / (root).
